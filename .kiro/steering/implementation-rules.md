# Implementation Rules

## Before Coding

Inspect:
- package.json
- src structure
- routes
- Tailwind configuration
- Vite configuration
- public/assets
- root assets
- existing logo
- existing provider icons
- existing footer/config/API mechanisms
- current components

Do not replace the application blindly.

## Scope

Only modify the Shopey marketing site.

Do not change ecommerce business logic or the app at https://app.shopey.tech.

## Architecture

Use reusable components and keep configuration/data separate from presentation.

Recommended component boundaries:
- Header
- Hero
- FeatureStrip
- FeatureGrid
- TechnologyGrid
- ScreenshotShowcase
- Pricing
- FAQ
- FinalCTA
- Footer

Do not over-abstract.
