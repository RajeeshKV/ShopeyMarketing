# Shopey Marketing Design System

## Character

Premium, modern, minimal, trustworthy, technically credible and approachable for small businesses.

## Layout

Use a centered responsive container with strong alignment.

Desktop:
- generous horizontal breathing room
- compact section spacing
- clean grids
- controlled text widths

Mobile:
- comfortable touch targets
- natural stacking
- no horizontal overflow
- preserve hierarchy

## Typography

Use a modern sans-serif.

Hero:
- small eyebrow
- bold compact headline
- readable supporting copy
- strong primary CTA

Sections:
- strong but not oversized headings
- muted supporting copy
- compact metadata

Avoid oversized hero text that consumes the whole viewport.

## Colors

Primarily:
- white / near-white surfaces
- black / near-black text
- neutral gray secondary text
- subtle gray borders
- restrained green only for positive/success states

Do not introduce a large unrelated color palette.

## Cards

Cards should have:
- subtle borders
- restrained shadows
- consistent radius
- compact padding
- strong alignment
- clear hierarchy

## Buttons

Primary:
- dark/near-black
- white text
- compact
- rounded, not excessively pill-shaped

Secondary:
- light/white
- visible border
- dark text

No gradient buttons.

## Icons

Use SVG icons.

Technology cards must use recognizable provider logos/marks, not first-letter placeholders.

## Technology Providers

Where applicable, represent:
- .NET
- React
- Vite
- Supabase
- Cloudinary
- Google Authentication
- Razorpay
- Brevo
- SMS API/provider support

Use repository assets when available. Otherwise use appropriate recognizable SVG/brand marks.

## Footer

Keep the footer quiet, dense and premium.

Support:
- brand block
- navigation
- support/legal
- configurable contact/social links
- copyright
