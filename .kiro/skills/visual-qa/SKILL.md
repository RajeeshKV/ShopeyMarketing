# Visual QA Skill

## Desktop

Verify:
- header proportions
- logo
- navigation
- hero
- CTA
- feature sections
- technology logos
- screenshots
- pricing
- FAQ
- final CTA
- footer

## Mobile

Verify:
- navigation
- hero stacking
- heading wrapping
- CTA
- cards
- technology grid
- screenshots
- pricing
- FAQ
- form
- footer
- no horizontal overflow

## Functional

Verify:
- Live Demo -> https://app.shopey.tech
- Demo navigation removed
- Demo section removed
- customer testimonial section removed
- footer Get Your Store removed
- email/phone/WhatsApp/Instagram links work
- no broken assets
- no console errors

## Completion

Do not stop at a build that merely passes. Iterate until obvious visual differences from the reference are corrected.
