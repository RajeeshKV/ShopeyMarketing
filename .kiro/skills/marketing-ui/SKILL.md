# Marketing UI Skill

Use this skill for all Shopey marketing UI work.

## Workflow

1. Inspect the repository and assets.
2. Read the steering files.
3. Identify desktop/mobile reference assets.
4. Identify supplied logo/provider assets.
5. Extract layout, typography, spacing, card and responsive patterns from the reference.
6. Implement with React + TypeScript + Tailwind.
7. Perform a dedicated polish pass.
8. Run typecheck/build/lint.
9. Perform desktop and mobile visual QA.

## Rules

The reference is the visual source of truth.

Do not:
- create a generic landing page
- embed screenshots as the whole page
- replace provider logos with initials
- replace the supplied logo with text
- add unrelated sections
- add excessive animation
- add excessive gradients

The final result must look like a finished commercial website.
