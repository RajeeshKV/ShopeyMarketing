# Design Reference Skill

## Analyze Before Coding

Determine:
- max content width
- header height
- navigation spacing
- hero proportions
- typography scale
- CTA dimensions
- section spacing
- card dimensions
- border/radius treatment
- shadow intensity
- footer structure
- mobile stacking
- breakpoints

## Assets

Inspect repository assets for:
- desktop reference
- mobile reference
- Shopey logo
- favicon/icon
- provider logos
- product screenshots

Use actual assets when supplied.

## Never

- invent asset filenames
- redraw the logo
- use screenshot as the website UI
- use random stock illustrations
- use provider initials as logos

## Improvements

Only make improvements that preserve the reference intent:
- tighter alignment
- better spacing
- improved responsive behaviour
- better accessibility
- cleaner icon treatment
- subtle hover/focus states
